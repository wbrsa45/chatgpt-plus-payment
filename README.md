在比较不同方式时，重点看最终付款页，而不是只看宣传中的“支持人民币”：

- 结账时实际扣款是人民币还是外币；
- 汇率、手续费是否另计；
- 购买的是月付、连续多月订阅，还是其他服务；
- 到期是否自动续费；
- 订阅是否开在你自己的 ChatGPT 账号上；

这些细节直接影响最终花费和后续管理。页面写了“人民币支付”，但如果付款前才发现需要提交额外账号凭证或选择自动续费，体验就和一笔普通的人民币订单不太一样。
